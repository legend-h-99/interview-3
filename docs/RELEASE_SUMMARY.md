# ملخص ما تم إنجازه

## المنصة

- اسم المنصة: `interview 3`.
- لا يظهر اسم الحساب داخل واجهة النظام.
- النشر متاح عبر GitHub Pages وSites.
- بوابة المتقدمين منفصلة عن الواجهات الداخلية.
- الحد الأقصى للاستخدام المتزامن: 150 مستخدم في نفس الوقت.

## بيانات الكلية والقسم

- الكلية: الكلية التقنية للاتصالات والمعلومات.
- القسم: قسم التقنية الخاصة للصم وضعاف السمع.
- رئيس القسم / رئيس اللجنة: رائد الغفيلي.
- إدارة الكلية تظهر كقائمة اختيار.
- وكيل شؤون المتدربين يظهر ضمن التقارير والتصدير.

## بوابة المتقدمين

- يبحث المتقدم بالاسم أو رقم الهوية.
- إذا كان المتقدم موجودا في بيانات القبول تظهر بياناته لاستكمال الناقص.
- إذا لم يكن موجودا يتم إدخال البيانات المطلوبة.
- بعد الإصدار تظهر بطاقة عامة تحتوي الاسم ورقم الانتظار فقط.
- تظهر في بطاقة الانتظار عبارة المصدر: مسجل من البوابة أو مسجل بشكل مباشر.
- لا تظهر الأسئلة أو الدرجات أو بيانات اللجان في بوابة المتقدم.
- يدعم النظام الإدخال بأي لغة وبأرقام عربية أو فارسية أو إنجليزية.

## اللجان والمقابلات

- توجد ثلاث لجان ثابتة: لجنة 1، لجنة 2، لجنة 3.
- المدرب يختار رقم اللجنة أولا.
- بعد اختيار اللجنة تظهر قائمة أسماء المدربين كاملة مع رقم الحاسب.
- يمكن اختيار مدرب واحد أو أكثر.
- يمكن اختيار مترجم بشكل اختياري من قائمة ثابتة.
- قائمة المتقدمين في لجنة المقابلات تعرض جميع المتقدمين، وليس فقط المسجلين في اللجنة.
- بعد اعتماد تقييم المدرب تظهر الدرجة وينتقل النظام لإجراء مقابلة مع متقدم آخر.
- صفحة المقابلات تعرض نموذج الدرجات فقط، ولا تعرض بطاقات الوثائق أو سجل التدقيق أو إجابات الأسئلة الجاهزة.
- أسئلة المعلومات العامة تظهر كسؤال عادي مع خانة إدخال الدرجة.

## التقييم والأسئلة

- مجموع التقييم من 50 درجة.
- الإشارة من 25.
- المظهر العام من 5.
- المعلومات العامة من 15.
- سرعة الاستجابة للتعليمات من 5.
- أسئلة الرياضيات والإنجليزي ثابتة، ويعرض النظام للمتقدم مجموعة أسئلة بسيطة.
- توجد بنود نعم/لا للصعوبات المصاحبة، ضعف السمع، لغة الإشارة، ضعف القدرات، والتميز.
- الملاحظات محفوظة ضمن ملف المتقدم.

## التقارير والرسوم

- تصدير PDF.
- تصدير Excel/CSV.
- الرسوم والمؤشرات تظهر في الواجهات الداخلية.
- تقرير PDF يحتوي قسم الرسوم والمؤشرات.
- Excel/CSV يبقى للتفاصيل الرقمية والبيانات.
- التقارير والجداول تعرض المصدر للمتقدم.

## التصميم

- تم تحسين الواجهة المتجاوبة.
- تم توثيق التحديثات في Figma.
- تم إنشاء عرض Figma Slides مختصر للمنصة.
