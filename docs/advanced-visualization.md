# Interview 3 Advanced Data Visualization

## الهدف

تضيف صفحة `تصورات متقدمة` لوحة مستقلة لعرض بيانات المقابلات برسوم ثنائية وثلاثية الأبعاد داخل تطبيق React نفسه. الصفحة تعتمد على بيانات المتقدمين الحالية ولا تضيف قاعدة بيانات أو API جديد.

## مصادر البيانات

- REST: تستخدم نفس مصدر `/api/applicants` الموجود في النظام.
- GraphQL: موضّح في الواجهة كمسار جاهز للتوسيع باسم `analyticsApplicants`.
- WebSocket: موضّح كمحاكاة تحديث حي يمكن ربطها لاحقًا على `/live/interviews`.

## الرسوم

- Three.js: أعمدة ثلاثية، سطح ثلاثي، شبكة علاقات، وخريطة حرارية.
- SVG: خط زمني، مخطط نقاط، توزيع حالات، ومتوسطات الدرجات.
- التصفية: كل المتقدمين، منصة قبولي، تسجيل مباشر، وتم تقييمهم.

## الأداء

- استخدام `InstancedMesh` للأعمدة والخريطة الحرارية.
- تقليل تفاصيل الأجسام الهندسية في الشبكة والسطح.
- تحميل Three.js عند فتح الصفحة فقط.
- ضبط `devicePixelRatio` لتقليل تكلفة الرسم على الأجهزة المحمولة.

## الوصول

- الصفحة تحمل `aria-label`.
- أزرار الأنماط تعمل كـ `tablist`.
- المشهد يدعم لوحة المفاتيح: الأسهم للتدوير والتكبير.
- توجد حالة بديلة واضحة إذا لم يتوفر WebGL.
